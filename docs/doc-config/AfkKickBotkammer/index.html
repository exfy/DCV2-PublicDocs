AFK kick Botkammer

✨DCV3 exklusiv

Diese Funktion ist nur in DCV3 verfügbar.

Diese Funktion kickt Spieler aus der Botkammer, die länger als die konfigurierte Zeit AFK sind.

Funktionsbeschreibung​

Wenn ein Spieler die Botkammer betritt, wird ein Timer gestartet. Wenn der Spieler für die konfigurierte Zeit inaktiv bleibt, erhält er eine Warnung. Nach einer weiteren konfigurierten Zeit wird der Spieler aus der Botkammer gekickt.

Config - dynamicconfig.json​

 "bot_verkaufszone_afkkick_enabled": false,
  "bot_verkaufszone_warnung_nach_ms": 60000,
  "bot_verkaufszone_warnung_msg": "Afk? Bitte sei aktiv, sonst wirst du gekickt!",
  "bot_verkaufszone_kick_nach_ms": 60000,
  "bot_verkaufszone_kick_msg": "Du wurdest gekickt, da du afk warst!",
  "bot_verkaufszone_kick_befehl": "p kick %player%",
  "bot_verkaufszone_2ten_kick_befehl_enabled": false,
  "bot_verkaufszone_kick_befehl2": "p kick %player%",
  • bot_verkaufszone_afkkick_enabled - Aktiviert/Deaktiviert die AFK Kick Funktion in der Botkammer.
  • bot_verkaufszone_warnung_nach_ms - Zeit in Millisekunden bis die AFK Warnung gesendet wird.
  • bot_verkaufszone_warnung_msg - Nachricht die gesendet wird, wenn die AFK Warnung ausgelöst wird.
  • bot_verkaufszone_kick_nach_ms - Zeit in Millisekunden bis der AFK Kick ausgeführt wird.
  • bot_verkaufszone_kick_msg - Nachricht die gesendet wird, wenn der AFK Kick nach der Warnung ausgeführt wird.
  • bot_verkaufszone_kick_befehl - Befehl der ausgeführt wird, wenn der AFK Kick ausgeführt wird. %player% wird durch den Spielernamen ersetzt.
  • bot_verkaufszone_2ten_kick_befehl_enabled` - Wenn true, wird ein zweiter Kickbefehl ausgeführt.
  • bot_verkaufszone_kick_befehl2 - Zweiter Befehl der ausgeführt wird, wenn der AFK Kick ausgeführt wird. %player% wird durch den Spielernamen ersetzt. (Befehl verzögert, wenn man deny/kick machen will etc.)
