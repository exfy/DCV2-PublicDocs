Name Auflösung

Variable NameBeschreibungBeispiel
getName(uuid)Ersetze "uuid" durch die UUID, wo du den Namen erhalten möchtest. Der Name wird nur durch TabListe aufgelöst, sprich der Spieler muss auf dem Server zur Laufzeit Online gewesen sein. NickName Auflösung ist vorhanden. Diese Funktion unerstützt keine Offline UUID auflösung.75b935d7-7dbf-406xxxxxxxxxxxx

Beispiel:

{
  "actionname": "DisplayMessageInChatAction",
  "actiondisplayname": "DisplayMessageInChatAction",
  "minimalReqVersion": 1,
  "data": {
    "message": "Name: getName(%uuid%)"
  }
}
danger

Achtung! getUUID und getName ist ggf. nicht mit Math kompatibel in einem String.
