Variablen in Events

Zeit-Event​

Variable NameBeschreibungBeispiel
event_zeitHHMMZeitpunkt des Events in HH:MM03:45

Lampen-Event​

Variable NameBeschreibungBeispiel
event_lampposGibt die XYZ Koordinaten der Lampe mit123,45,-4567

Chat-Event​

Variable NameBeschreibungBeispiel
event_chatWithColorCodesChat mit Colorcodes§9Das ist eine Blaue Nachricht mit gelben §eGelb!
event_chatWithoutColorCodesChat ohne ColorCodesDas ist eine Blaue Nachricht mit gelben Gelb!

Ankauf-Event​

Variable NameBeschreibungBeispiel
event_ankaufItemDisplayNameItem Display NameStone
event_ankaufMaterialItem Materialmaterial:stone
event_ankaufLoreLine1Sign Lore 1 (sign)Das ist Sign Zeile 1
event_ankaufLoreLine2Sign Lore 2 (addsign)Das ist Sign Zeile 2
event_ankaufSignDateSign Datum17.10.2024
event_ankaufSignUserSign UsernameUsername
event_ankaufPlayerNameEvent UsernameUsername
event_ankaufPlayerUUIDEvent UUIDUsername
event_ankaufItemCountMenge des Items3
event_ankaufspreisSumme des ganzen Ankaufs123.45
